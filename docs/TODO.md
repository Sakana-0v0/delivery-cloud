## ⏸️ CRAWLER-003 — 爬虫后续优化 ⏸️ 封档

> **来源**：#CRAWLER-002 Iteration 3 交付后沉淀的优化项
> **创建时间**：2026-09-05
> **当前模型**：qwen-plus（用户已确认）

| 优化项 | 描述 | 工作量 | 何时做 |
|--------|------|--------|--------|
| **并发调优** | 当前 `max_concurrency: 5`，qwen-plus 限速 25 QPS（免费 5 QPS），可以按套餐调整 | 2 分钟（改 config） | 跑过 1-2 次发现慢时 |
| **品牌 prompt** | 根据餐厅风格定制 prompt（高端 / 亲民 / 猎奇等），需要产品/运营提供品牌调性 | 30 分钟（含多轮调优）| 品牌调性明确后 |
| **LLM 结果缓存** | 同名商品的 description 缓存到本地，避免重复调 LLM | 半天 | 数据量大、重复商品多时 |
| **错误重试 + 指数退避** | LLM 调用失败时自动重试 3 次（间隔 1s/2s/4s）| 1 小时 | 偶发网络不稳时 |
| **批量并发优化** | 当前用 ThreadPoolExecutor 5 并发，可以提到 10-20（按 QPS 配额）| 10 分钟 | 爬取量大时 |
| **LLM 输出校验** | 检查 LLM 输出是否包含英文（用正则）、长度是否合理，不通过自动重试 | 1 小时 | 内容质量要求高时 |
| **多 LLM 备选** | 支持 fallback：qwen-plus 失败时切到 deepseek | 1 小时 | 单一 LLM 不稳定时 |
| **进度可视化** | 当前 stdout 日志，可以加 tqdm 进度条 | 10 分钟 | 用户体验优化 |
