## 六、常见问题排查

### Q1: 管理员登录页面打不开

**解决**：浏览器直接输入 `http://localhost:5173/admin/login`（首页无入口链接）

### Q2: CORS 错误

**症状**：浏览器控制台报 `Access-Control-Allow-Origin has multiple values`

**检查**：
1. del-gateway 服务是否正常
2. 业务服务 SecurityConfig 中是否移除了 CORS 配置（应只剩网关统一处理）

### Q3: 切换页面卡死

**检查**：
1. 浏览器 DevTools → Network 面板是否显示"已取消"的请求
2. 6 个管理页面是否都添加了 `cancelled` 标志位 + `onUnmounted`

### Q4: 验证码收不到

**检查**：
1. del-message 服务日志：是否有 `[MessageChannel] 邮件消息已投递到 MQ`
2. del-message 服务日志：是否有 `[MQ-Email] 收到邮件事件`
3. 邮箱垃圾箱

### Q5: 统计接口返回 null

**已知问题**：del-stats 服务的 `SalesTrendDTO.points` 和 `HotProductVO` 数据结构与 del-order/del-product 不匹配。

**状态**：已记录在 P1 待修复项，不影响日常管理操作。
