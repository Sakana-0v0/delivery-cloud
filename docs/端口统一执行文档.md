## 三、后续操作

### 3.1 Nacos 网关路由配置

需确认 Nacos 中的 `del-gateway.yml` 路由配置端口与上述一致：

```yaml
spring:
  cloud:
    gateway:
      routes:
        - id: del-user
          uri: http://localhost:10003  # 或 lb://del-user
        - id: del-admin
          uri: http://localhost:10002  # 或 lb://del-admin
        - id: del-product
          uri: http://localhost:10000  # 或 lb://del-product
        - id: del-order
          uri: http://localhost:10001  # 或 lb://del-order
        - id: del-payment
          uri: http://localhost:10004  # 或 lb://del-payment
        - id: del-message
          uri: http://localhost:10005  # 或 lb://del-message
```

### 3.2 Feign 调用验证

| 调用方 | 被调用服务 | Feign 客户端 | 端口状态 |
|--------|-----------|-------------|---------|
| del-order | del-product | `ProductFeignClient` | ✅ del-product 端口 10000 未变 |
| del-payment | del-order | `OrderClient` | ✅ 使用服务名负载均衡 |
| del-payment | del-user | `UserClient` | ✅ del-user 端口 10003 未变 |

### 3.3 支付回调地址

`del-payment` 的支付宝回调地址需同步更新为新端口：

```yaml
# del-payment 配置（可能在 Nacos alipay.yml 中）
alipay:
  notify-url: http://your-domain.com:10004/api/v1/payments/notify
  return-url: http://your-domain.com:10004/api/v1/payments/return
```
